# 글로우팁 (GlowTip) — 일회용 네일아트 쇼핑

**바르는 일회용 젤 네일아트 키트** 쇼핑 데모입니다. 붙이는 스티커의 대안으로, 글리터·큐빅·프렌치·무광
스타일의 젤 네일을 한 번만 즐길 수 있는 컨셉을 담았습니다. 빌드가 필요 없는 순수 정적 사이트로,
브라우저에서 카탈로그 탐색, 인터랙티브 손 SVG 미리보기, 피부톤·상황 추천, 찜/장바구니, 모의결제,
월간 컬러 박스 구독을 모두 체험할 수 있습니다.

## 라이브 데모

**https://clsoftlab-lang.github.io/single-use-nail-art/**

## 기능

- **카탈로그** — 34종 가상 키트, 스타일·시즌·톤 필터, 가격 슬라이더, 검색, 정렬.
- **제품 상세** — 색상 스와치, 구성품, 사용법 스텝, 리뷰(모달).
- **네일 미리보기** — 컬러를 고르면 인라인 SVG 손톱이 즉시 리컬러. 글리터/큐빅/프렌치/무광 전환.
- **장바구니 + 모의결제** — 담기/삭제/수량 조절, 가상 결제.
- **정기구독** — 3종 월간 컬러 박스 구독/해지.
- **찜** — 마음에 든 컬러 저장(로컬).
- **컬러 매칭 추천** — 피부톤(웜/쿨) + 상황 선택 → 점수 기반 추천.
- **반응형** 모바일 우선, `prefers-color-scheme` 라이트/다크 지원.
- **상태**는 `localStorage`에 저장(try/catch + 원탭 초기화).

## 미리보기 · 추천 동작 원리

- **미리보기**(`modules/svgNails.js`): `renderHandSVG({ hex, accentHex, style })` 가 손을 순수
  인라인 SVG로 그립니다. 손톱은 선택 `hex`로 채우고, `style`에 따라 프렌치 팁 곡선, 글리터 점,
  큐빅 마름모, 무광 레이어를 덧입힙니다. 스와치 칩이나 "미리보기에 적용" 버튼을 누르면 즉시 갱신됩니다.
- **추천**(`modules/recommend.js`): `shadeRecommend(products, { warmCool, situation, limit })`는
  순수 함수로, 톤 일치 +3, 상황(vibe) 일치 +4, 평점 가중치를 더해 내림차순 정렬합니다.
  `check.mjs`에서 단위 테스트합니다.

## 데모 모드 한계 (중요)

- **모든 제품·브랜드·가격·리뷰는 가상입니다.** 실제 상품이 아닙니다.
- **결제·구독은 시뮬레이션**입니다 — 실제 금전 거래나 주문이 발생하지 않습니다.
- **상태는 브라우저 `localStorage`에만 저장**됩니다 — 실제 DB가 아니며 기기별로 유지되고 언제든 삭제될 수 있습니다.
- **계정·로그인·개인정보(PII) 수집이 없습니다.**
- 실제 서비스라면 백엔드, 실제 카탈로그·재고, 실 결제, 인증이 추가되어야 합니다.

## 🤖 AI 기능 (API 연동)

이 앱에는 작지만 교체 가능한 **AI 레이어**가 들어 있고, 세 가지 기능을 **AI 어시스턴트 ✨** 탭
(및 제품 상세 모달)에서 사용할 수 있습니다.

1. **AI 네일 컬러/스타일 추천 챗봇** — 피부톤·상황·취향을 말하면 앱의 제품 데이터와
   `shadeRecommend` 추천 엔진에 근거해 컬러를 골라줍니다.
2. **상황별 코디 추천** — 상황을 고르면 옷차림 + 어울리는 네일 코디를 제안합니다.
3. **상품 설명/후기 요약 생성** — 각 제품 상세의 **AI 요약 ✨** 버튼으로 설명·후기를 요약합니다.

### 데모 = 목업(기본값)

`ai/config.js` 의 `AI_ENDPOINT` 가 비어 있으면(`""`) 모든 기능이 **결정론적 한국어 MockProvider**로
동작합니다 — 백엔드도, API 키도, 네트워크도 필요 없습니다. 라이브 데모가 쓰는 기본 모드입니다.

### 실 AI(Claude) 켜기

실제 추론은 [`server/`](./server/) 백엔드 프록시를 경유합니다. 그래서
**키는 오직 서버 측에만 존재하고, 브라우저나 리포지토리에는 절대 두지 않습니다.**

```bash
cd server
npm install
cp .env.example .env          # ANTHROPIC_API_KEY=sk-... 설정
npm start                     # POST http://localhost:8787/api/ai  (모델: claude-opus-5)
```

그런 다음 프런트엔드를 연결합니다:

```js
// ai/config.js
export const AI_ENDPOINT = "http://localhost:8787/api/ai";
```

브라우저는 `{ task, payload }` 를 프록시로 보내고, 프록시가 Claude
(`client.messages.stream`, 모델 **`claude-opus-5`**)를 호출해 텍스트를 스트리밍합니다.
`askAI()` 는 목업이든 백엔드든 동일하게 스트리밍으로 응답합니다.

> **🔒 API 키는 서버 측에만.** `ai/config.js`·브라우저 코드·커밋되는 파일 어디에도 키를 넣지 마세요.
> `.env` 는 git 에서 제외되고, `.env.example` 은 플레이스홀더만 담습니다. `check.mjs` 는
> `AI_ENDPOINT` 가 비어 있지 않거나 실제 키 형식이 리포지토리에 있으면 빌드를 실패시킵니다.
